# Vitalis · Sistema de Gestión de Citas Médicas

Prototipo web estático desarrollado por el **Grupo 3 · Medisync** (FESC - Ingeniería de Software) para el caso de estudio del Hospital Universitario Erasmo Meoz (Cúcuta)[cite: 1].

## Funcionalidades implementadas
- **Login de Personal Autorizado (`ACT-02`)**: Control de acceso para personal administrativo y médico mediante `login.html` y protección de sesión en `dashboard.html`[cite: 1].
- **Portal del Paciente (`ACT-01`)**: Solicitud de citas sin registro (`CU-02`), validación de bloques ocupados y consulta de estado (`CU-04`)[cite: 1].
- **Gestión Administrativa (`CU-06` / `CU-07`)**: Visualización de solicitudes y aprobación/rechazo en tiempo real usando `localStorage`[cite: 1].
